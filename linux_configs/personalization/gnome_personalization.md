# Personalización de GNOME

En la tieda de Software, descargamos las siguientes apps:
- Extension Manager (Matthew Jakeman)
- GNOME Tweaks (The GNOME Project)



## Instalación de extensiones
Abrimos la aplicación **Extension Manager**.
En la pestaña superior nos vamos a **browse** y en la barra de busqueda, ajustamos **None** a **Downloads**.

Búscamos e instalamos las siguientes extensiones:
_Nota: Esta es mi lista personal, puede variar según gustos y necesidades_.

- Blur my Shell
- Caffeine
- Clipboard Indicator
- Coverflow Alt-Tab
- Dash to Dock
- Extension List
- Just Perfection
- Logo Menu
- Places Status Indicator
- Removable Drive Menu
- Space Bar
- Tilling Assistant
- User Themes
